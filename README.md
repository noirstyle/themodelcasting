# NOIR CASTING Catalog

## GitHub Pages'e yükleme

1. Bu klasörü GitHub'da yeni bir repository içine yükle.
2. `images/model-01` ve `images/model-02` klasörlerini oluştur.
3. Her modelin klasörüne `01.jpg` ile `10.jpg` arasında fotoğraflar koy.
4. `models.js` içindeki isim, boy, kilo ve diğer bilgileri değiştir.
5. Repository Settings → Pages → Deploy from branch → main seç.
6. Birkaç dakika sonra siten yayınlanır.

Yeni model eklemek için `models.js` dosyasındaki `models` dizisine aynı formatta yeni bir model objesi ekle.
